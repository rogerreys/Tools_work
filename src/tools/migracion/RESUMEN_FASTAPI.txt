================================================================================
🔧 FUNCIÓN PRINCIPAL: migrate_for_api()
================================================================================

Ubicación: migrate_operations.py (línea ~200)

Firma:
------
def migrate_for_api(
    operations: Union[str, List[str]], 
    skip_execution: bool = False,
    auto_confirm: bool = True,
    base_path: Optional[str] = None
) -> Dict[str, Union[bool, str, List[str], dict]]

Parámetros:
-----------
• operations      - String "118043,118044" o lista ["118043", "118044"]
• skip_execution  - True = solo actualiza archivos (default: False)
• auto_confirm    - True = envía 's' automáticamente (default: True)
• base_path       - Ruta del proyecto (default: None = ubicación del script)

Retorna:
--------
{
    "success": bool,              # True si todo OK
    "message": str,               # Mensaje descriptivo
    "operations": List[str],      # IDs procesados
    "files_updated": {            # Ocurrencias reemplazadas
        "delete_file": int,
        "copy_file": int
    },
    "execution_skipped": bool,    # True si no ejecutó
    "execution_output": dict,     # Output del JAR (o None)
    "timestamp": str,             # ISO 8601
    "error": str or None          # Error (None si success=True)
}

OPCIÓN 2: Agregar a tu FastAPI existente
-----------------------------------------
from Migracion.migrate_operations import migrate_for_api
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

class MigrationRequest(BaseModel):
    operations: str
    skip_execution: bool = False
    auto_confirm: bool = True

@app.post("/api/migrate")
async def migrate(request: MigrationRequest):
    result = migrate_for_api(
        operations=request.operations,
        skip_execution=request.skip_execution,
        auto_confirm=request.auto_confirm
    )
    
    if not result["success"]:
        raise HTTPException(status_code=400, detail=result["error"])
    
    return result
